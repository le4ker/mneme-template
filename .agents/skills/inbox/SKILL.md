Capture a fleeting note in `Inbox/`.

Ask for a short title and optional content or context. Create
`Inbox/YYYY-MM-DD-<kebab-case-title>.md` using today's local date, with an H1
title followed by the content if provided. Run `make format` and report the
created path.
